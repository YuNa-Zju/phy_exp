# 仓库整理记录

2026-09-21 将原来散落在根目录的实验归入 `experiments/`，统一报告、图片、数据和程序的位置。合并两个交流功率因数与整流器目录后，共 23 个实验、44 份报告；所有报告版本均保留。各实验 README 列出了原文件名，不以作者姓名标记版本。

共享模板归入 `templates/`，原始模板源码在 `templates/legacy/`，课程讲义在 `references/`。旧模板的两份已编译 PDF 转存到本地 `.private/legacy-pdf/`，不再随源码提交。

## 图片

对现有图片和 PDF 配图生成预览，结合报告中的用途归类：

| 目录 | 内容 |
| --- | --- |
| `figures/diagrams/` | 实验原理、仪器结构、电路、光路与手绘示意 |
| `figures/plots/` | 拟合结果、残差、误差曲线、计算结果截图 |
| `figures/photos/` | 原始记录、实验现象照片、仪器屏幕截图 |

原有 293 个图片/PDF 文件中，有 47 个内容完全重复的副本，通过 SHA-256 比对后合并。现有实验目录内保留 242 个不同的配图文件；另外保留共享校名 PDF 和课程讲义。共享图按实际实验归属保留一份，报告通过相对路径引用。仅内容完全相同的文件合并，相似图片和不同数据版本均保留。

部分纯数字或聊天软件导出的文件名改为说明用途的名称，例如整流电路、双棱镜光路和干涉条纹。原 `2/`、`3/` 等数字子目录转为文件名前缀 `v02-`、`v03-`，用于区分原来的不同版本；它们不表示新的时间排序。

照片、扫描件及其元数据均未修改，也未做隐私检查。原始路径与新路径的完整关系在 [path-mapping.json](path-mapping.json)。当前没有被报告引用的资源仍保留，未因“未引用”而删除。

## 保留的旧问题

弗兰克赫兹实验的四张仪器截图原名为 `新建文件1.png` 至 `新建文件4.png`，现为 `figures/photos/示波器截图-01.png` 至 `示波器截图-04.png`。它们有 PNG 文件头，但本次 Pillow 预览无法读取；文件原样保留，当前报告没有引用它们。

部分报告中的原始数据占位图原本已被注释且文件不存在，此次继续保留注释，不补造数据。旧报告正文中的交叉引用、表格布局等可能仍有编译警告；本次修复目录、模板加载和阻断编译的路径问题，没有重新校订全部实验内容。

MATLAB 脚本中的输入数据和计算公式未因整理而改动，仅调整输出路径；程序中的作者信息按仓库维护者要求保留。原始照片中可能含姓名和学号，同样保持原样。隐私过滤只适用于 `.tex`。

迁移前的 371 个 Git 跟踪文件已备份到本地 `.private/before-reorganization.tar.gz`，归档内每个文件均与原件 SHA-256 一致；校验清单在 `.private/backup-manifest.json`。匿名化前的 TeX 原件也保留在 `.private/privacy-backups/`。这些路径被 Git 忽略，其他人的 clone 中不会出现。

公开对照表不包含本地敏感词。历史提交和已经发布的附件不会因当前工作区匿名化而被清理。

## Workflow 调整

移除旧 `com_host.yml` 的自建 runner 依赖，并删除扩展名不被 Actions 识别的旧 `compile_yml` 草稿，统一为 `reports.yml`。新的流程在 GitHub 托管 runner 上运行，在 TeX Live 2026 环境编译；先通过 TeX 隐私检查、路径检查和 Python 测试，再打包所有报告。任何一份报告失败都使构建失败，PR 和手动运行不触发发布，默认分支推送成功后才发布 Release。

共享模板直接加载随仓库保存的中文字体，避免机器上的字体安装差异；编译脚本以每份报告所在目录为工作目录，支持中文和空格路径，且为每份报告使用独立的临时输出目录。日志与发布产物统一放在 `build/`。

远端旧运行记录中，最近一次运行在没有执行步骤的情况下被取消；前一次失败没有可读取的任务日志，因此不能仅凭记录断言远端故障的唯一原因。新的 workflow 配置需提交到 GitHub 后才能验证实际 runner、容器下载和 Release 权限。
